# 研究生复试 / 保研面试模拟器 — 需求文档（PRD）

> 版本：v0.1（规划稿） · 更新：2026-06 ·
> 目标：本地桌面应用，模拟研究生复试 / 保研面试完整流程，AI 扮演面试官，
> 基于本地资料出题，全程语音对话，面试结束后输出详细评分报告。

---

## 1. 项目概述

一个跑在本机（macOS，Apple Silicon）的 **Electron 桌面应用**：

- 用户导入自己的**英语资料**、**专业课资料**和**简历**（PDF / Word）；
- 一键开始模拟面试，按「自我介绍 → 英语口语问答 → 专业课问答 → 简历提问」四阶段自动推进；
- AI 面试官（DeepSeek API）根据本地资料**智能出题、追问、点评**，全程语音对话；
- 面试结束生成**详细评分报告**（分项打分 + 改进建议 + 问答记录回放），并保存历史。

## 2. 已确认的技术决策

| 决策点 | 选择 | 说明 |
|---|---|---|
| 交互方式 | 语音对话 | 录音 → 语音识别 → AI 回答 → 语音合成播放 |
| AI 引擎 | DeepSeek API | 智能出题 / 追问 / 评分；需用户自备 API Key |
| 软件形态 | Electron 桌面应用 | 本机 Node v24 已就绪，无需 Rust |
| 语音识别 (ASR) | 本地 Whisper | 免费、隐私好；macOS 用 MLX 优化版 |
| 语音合成 (TTS) | Edge TTS | 免费在线合成，音色自然，支持中英双语 |
| 资料格式 | PDF + Word (.docx) | 简历同格式 |
| 评分反馈 | 详细评分报告 | 分环节打分 + 建议 + 历史记录 |

## 3. 使用场景

1. 用户准备复试 / 保研面试，想反复练习自我介绍、英语口语、专业课问答；
2. 打开应用 → 选择面试模式 → 开始模拟面试；
3. 面试过程中像真实面试一样与 AI 面试官语音交流；
4. 结束后查看评分报告，针对薄弱环节改进，隔几天再练。

## 4. 面试流程设计（核心）

### 4.1 总流程状态机

```
[空闲 idle] ──开始──▶ [自我介绍 intro]
                            │ 结束
                            ▼
                    [英语口语问答 english] ◀── 可跳过 / 提前结束
                            │ 结束
                            ▼
                    [专业课问答 major]
                            │ 结束
                            ▼
                    [简历提问 resume]
                            │ 结束
                            ▼
                    [评分报告 report] ──▶ [历史记录]
```

- 每个阶段可：**开始 / 暂停 / 继续 / 跳过 / 提前结束**；
- 阶段切换由用户确认（AI 问"还有补充吗？"后点击"进入下一环节"）；
- 整场面试随时可"结束并出报告"。

### 4.2 阶段一：自我介绍（intro）

- 计时 2~3 分钟（可配置），倒计时提醒；
- AI 面试官先开场（中文）："请先做个自我介绍"；
- 结束后 AI 基于自我介绍内容追问 1~2 个问题（如：项目细节、为什么选这个方向、本科最难忘的经历）。

### 4.3 阶段二：英语口语问答（english）

- AI 面试官全程用**英语**；
- 问题来源：用户的英语资料（若资料含专业英语，则偏专业话题；否则偏生活/学术通用话题）；
- 建议 4~6 题（可配置），每题 1~2 轮追问；
- 中途可用中文说"听不懂"或"换一题"，AI 识别后降级提示。

### 4.4 阶段三：专业课问答（major）

- AI 面试官以中文提问，题目基于专业课资料内容，覆盖不同章节/知识点；
- 支持由浅入深追问（概念 → 原理 → 应用 / 场景题）；
- 建议 5~8 题（可配置）；答不上时可选择"提示"或"换一题"。

### 4.5 阶段四：简历提问（resume）

- 解析简历，提取：教育背景、成绩、科研/项目经历、竞赛获奖、技能、证书等；
- AI 针对**项目经历细节**（角色、难点、成果、数据）、**简历矛盾点**、**动机类问题**（为什么读研/为什么选本校/职业规划）提问；
- 建议 4~6 题。

### 4.6 出题与追问策略（AI 面试官人设）

- 系统提示词定义面试官角色，随阶段切换人设（中文面试官 / 英语口语考官 / 专业课教授 / 简历深挖官）；
- 出题时从解析后的资料库中**检索相关片段**喂给 LLM（控制上下文长度），避免全量塞入；
- 追问规则：回答不完整 → 追问细节；回答错误 → 纠正性追问；回答流畅 → 加深难度。

## 5. 功能需求

### FR-1 资料管理
- 导入 PDF / Word 资料，按「英语资料」「专业课资料」分类管理；
- 支持多份文件、文件夹批量导入；解析后显示文件名、页数、字数、内容预览；
- 简历单独导入，解析为结构化信息（可手动修正）。
- 解析技术：`pdf-parse`（PDF）、`mammoth`（docx），文本存入本地索引。

### FR-2 语音交互
- 说话：点击"按住说话"或"开始录音"按钮 → 麦克风录音；
- 识别：本地 Whisper（mlx-whisper / faster-whisper，Apple Silicon 优化）转文字，中英文自动识别；
- 播放：AI 回答通过 Edge TTS 合成（中文面试官 zh-CN 声、英语考官 en-US 声），支持自动播放 + 重播；
- 语音管线异常（如无麦克风权限、模型未下载）时降级为文字输入模式。

### FR-3 AI 面试官（DeepSeek）
- 用户配置 API Key（本地保存，不联网上传）；
- 调用 OpenAI 兼容接口 `https://api.deepseek.com`；
- 对话带上下文（本阶段已发生的问答），并按需注入资料片段；
- 支持**中断**：AI 正在说话时可按"打断"。

### FR-4 计时与流程控制
- 全局计时器 + 每阶段计时；自我介绍倒计时提示；
- 阶段进度条（4 个环节的完成状态）；
- 跳过 / 提前结束 / 重来一次。

### FR-5 评分报告
- 面试结束后 AI 生成结构化评分（JSON），前端渲染为报告：
  - **自我介绍**：内容结构 / 亮点突出 / 表达流畅 / 时长控制
  - **英语口语**：流利度 / 发音 / 语法 / 内容质量 / 应变
  - **专业课**：知识准确性 / 逻辑性 / 深度 / 追问应对
  - **简历问答**：项目理解深度 / 一致性 / 临场应变
  - **综合**：总分 + 总体评价 + 改进建议清单（按优先级）
- 报告含**完整问答记录回放**（问题、你的回答、AI 点评，可试听语音）；
- 可导出为 Markdown / PDF / 打印。

### FR-6 历史记录
- 每次面试保存为一条记录（时间、模式、各环节得分、报告）；
- 支持查看历史报告、对比两次练习的得分变化。

### FR-7 设置页
- DeepSeek API Key（保存 / 测试连通性）；
- 面试参数：自我介绍时长、各环节题数、是否允许提示/换题、语音开关、音量、语速；
- 语音诊断：Whisper 模型下载状态、麦克风测试、TTS 试听；
- 数据目录管理（资料、录音、历史记录存放位置）。

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 隐私 | 除 DeepSeek API 与 Edge TTS 外全部本地；麦克风录音、资料不离开本机 |
| 离线能力 | 无网络时：面试流程仍可走（AI 不可用则提示），历史记录可查看 |
| 性能 | 界面流畅；Whisper 识别 30s 音频 < 10s（MLX 加速）；启动 < 3s |
| 权限 | macOS 麦克风权限申请；首次运行引导配置 |
| 稳定性 | 语音管线任一环节失败可降级文字，不中断面试 |
| 兼容 | 目标 macOS 26 (Apple Silicon)；数据目录可迁移 |

## 7. 技术架构

### 7.1 总体架构（Electron）

```
┌────────────────────────── 渲染进程 (React + Vite) ──────────────────────────┐
│  UI：设置页 / 资料库 / 面试页（四阶段 + 计时 + 语音控制）/ 报告页 / 历史页   │
│  录音 (getUserMedia + MediaRecorder) → webm/opus                            │
│  <audio> 播放 TTS mp3 · 打字输入兜底 · 报告渲染 / 导出                       │
└──────────────┬─────────────────────────────────────────────────┬───────────┘
               │ IPC (contextBridge, 安全隔离)                    │
┌──────────────▼─────────────────────────────────────────────────▼───────────┐
│                         主进程 (Node.js)                                    │
│  · 资料解析：pdf-parse / mammoth → 文本索引库 (本地 JSON/SQLite)            │
│  · 语音管线：ffmpeg-static 转 16kHz wav → 调 Python Whisper 子进程 → 文本   │
│  · TTS：msedge-tts (npm) → mp3 文件 → 回传渲染进程播放                      │
│  · AI：openai SDK (baseURL=DeepSeek) 出题/追问/评分                         │
│  · 存储：electron-store / SQLite（设置、资料索引、历史记录、报告）          │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 7.2 模块与选型

| 模块 | 选型 | 备注 |
|---|---|---|
| 桌面框架 | Electron 36+ | node v24 直接开发 |
| 前端 | React + Vite + TypeScript | electron-vite 脚手架 |
| PDF 解析 | pdf-parse | 文本抽取 |
| Word 解析 | mammoth | docx → 文本 |
| ASR | mlx-whisper（优先）或 faster-whisper | Python 3.13 子进程，模型 ~1GB 首次下载 |
| TTS | msedge-tts (npm) | 免费，需联网（可缓存） |
| LLM | openai npm SDK → DeepSeek | 结构化输出用 JSON mode |
| 音频转换 | ffmpeg-static | webm → wav 16k mono |
| 存储 | electron-store（设置）+ JSON 文件（历史） | 简单够用 |

### 7.3 单轮问答数据流（语音）

```
用户说话 → 录音(webm) → ffmpeg 转 wav → Whisper 识别 → 文本
        → 主进程组装上下文(阶段 + 资料片段 + 历史问答) → DeepSeek
        → 返回文本 + 阶段控制指令(换题/追问/结束) → Edge TTS 合成 mp3
        → 渲染进程播放 + 对话气泡展示
```

## 8. 关键实现要点与风险

| 风险 / 要点 | 应对 |
|---|---|
| Whisper 与 Python 3.13 兼容性 | 优先 mlx-whisper（Apple Silicon 原生）；安装时验证，必要时用 venv + 指定版本 |
| 麦克风权限（macOS） | 首次启动引导授权；Electron 需 `systemPreferences.askForMediaAccess` |
| 录音格式 | MediaRecorder 产出 webm，统一经 ffmpeg 转 16kHz wav 再识别 |
| DeepSeek 上下文长度 | 资料切片 + 按需检索注入，不整份塞入；对话保留最近 N 轮 |
| 结构化评分 | 提示词要求 JSON 输出，前端校验兜底，失败时重试一次 |
| Edge TTS 联网依赖 | 合成失败自动重试 + 降级为文字显示，不中断面试 |
| 大 PDF 解析 | 限制页数上限 + 进度提示；解析结果缓存 |
| 打包分发 | electron-builder 打 dmg；Whisper 模型不打包，首次运行引导下载 |

## 9. 开发里程碑

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| **M1 骨架** | electron-vite 项目 + 设置页 + 数据目录初始化 | 应用可启动，可保存 API Key，麦克风权限可用 |
| **M2 资料解析** | 导入 PDF/Word，英语/专业课分类，简历结构化解析 | 三份样例文件解析正确、可预览 |
| **M3 语音管线** | 录音 → Whisper → 文本；Edge TTS → 播放 | 中英文各测试一句，端到端 < 15s |
| **M4 面试流程** | 四阶段状态机 + DeepSeek 出题/追问 + 计时控制 | 完整跑通一场 20 分钟模拟面试 |
| **M5 评分报告** | 结构化评分 + 报告页 + 历史记录 | 面试后生成报告并可回看、对比 |
| **M6 打磨打包** | 降级兜底、异常处理、UI 打磨、dmg 打包 | 无网络/无 Key 场景不崩溃，打包可安装 |

## 10. 待补充确认的细节（请用户补充）

1. **自我介绍时长**：默认 2 分钟还是 3 分钟？
2. **各环节题数**：英语 4~6 题 / 专业课 5~8 题 / 简历 4~6 题，是否合适？还是希望更短（快速练习）或更长（全真模拟）？
3. **追问强度**：希望面试官温和（答不上就换题）还是严格（往深挖）？是否可配置？
4. **资料现状**：英语资料和专业课资料目前大概各有多少页 / 几份文件？（影响索引与出题策略）
5. **API Key**：是否已有 DeepSeek API Key？没有的话需要先去 https://platform.deepseek.com 注册充值（约 ¥10 够练几十场）。
6. **报告导出**：Markdown / PDF / 打印，需要哪几种？
7. **是否多专业方向**：专业课资料是否需要按方向（如计科/电子/数学）分库，出题时选方向？
8. **界面语言**：全中文界面（英语环节内容为英语），确认？
