# 面试模拟器（Interview Simulator）

> 研究生 **复试 / 保研 / 夏令营** 面试的本地 AI 模拟面试桌面应用。
> 四阶段全程语音对话 → 基于你自己的资料出题 → 贴合目标院校真实风格 → 结束后自动生成 16 项评分报告与参考答案。

## 🎯 它解决什么问题

自己对着 ChatGPT 练面试，最大的问题是「不像面试」：没有节奏、没人追问、没有压力、练完不知道自己差在哪。这个应用把整个过程结构化：

| | 直接和通用 AI 聊天 | 面试模拟器 |
|---|---|---|
| 流程 | 想聊到哪聊到哪 | 固定四阶段推进，自我介绍**带倒计时**，各环节题数可控 |
| 出题依据 | 通用问题 | 基于**你导入**的简历 / 专业课资料 / 英语材料出题 |
| 院校差异 | 无 | 录入学长学姐的院校风格与真题回忆，面试官尽量贴合该校风格 |
| 输入方式 | 打字 | 本地语音识别，**边说边出字**，面试官还会读出来 |
| 结果 | 聊天记录 | 16 项维度评分 + 总评 + 改进建议 + 问答回放 + 逐题参考答案 |
| 进步追踪 | 无 | 历史记录 + **任意两次对比**（总分与各维度变化） |
| 隐私 | 素材都发给服务商 | 资料 / 录音 / 报告**全在本机**，音频不出本机 |

## ✨ 功能特性

### 🗣️ 四阶段模拟面试

像真实复试一样推进，每阶段有独立面试官角色与规则：

| 阶段 | 面试官角色 | 语言 | 题数（默认） | 说明 |
|---|---|---|---|---|
| 🗣️ 自我介绍 | 复试面试官 | 中文 | 1 段 | 带**倒计时**（2 / 2.5 / 3 分钟可选）；说「完毕」后面试官点评并追问 1 个问题，也可跳过追问直接收尾 |
| 🇬🇧 英语口语 | 英语口语考官 | **全英文** | 5 题 | 话题覆盖自我介绍、家乡、学校、专业兴趣、读研规划、时事观点等，结合你导入的英语词汇/话题资料 |
| 📖 专业课 | 专业课面试官（教授） | 中文 | 6 题 | 基于专业课资料出概念理解 / 应用分析题；答完会点评正误并视追问深度继续追问 |
| 📄 简历提问 | 综合面试官 | 中文 | 5 题 | 结合简历 + 你现场做的自我介绍原文，深挖项目角色、难点、成果、数据、读研动机 |

每个问答环节都提供这些操作：

- 💡 **提示**：只给 1-2 条思考方向 / 关键词 / 公式方向，**不会直接给答案**
- 🔄 **换一题**：跳过当前题，重新出题
- ⏭ **下一题**：进入下一题
- 同一题答满 2 轮追问后，面试官会自然收尾本题（避免死磕）

顶部实时显示：总用时、自我介绍剩余秒数、当前题号（第 3/6 题）、绑定学校。

### 🎭 面试官风格可调

4 种预设（复制自实际提示词）：

| 预设 | 实际行为 |
|---|---|
| **温和引导** | 语气亲切、多肯定鼓励，答错先认可努力再委婉纠正，不施压，节奏舒缓 —— 适合初次练习 |
| **标准型** | 礼貌正式、节奏适中，像真实复试一样客观，追问适度 —— 默认 |
| **压力型** | 语速偏快、气场严肃，连续追问、适当打断并质疑漏洞 —— 练抗压 |
| **学术深挖** | 重点追问原理深度与逻辑严密性，偏好"为什么""推导一下""和前沿的联系" |

再加 3 个 1-5 档滑块 + 自由描述，可以精细调控：

| 滑块 | 1 档 | 3 档（默认） | 5 档 |
|---|---|---|---|
| **追问深度** | 几乎不追问 | 常规追问一层 | 穷追不舍，追问到数据/推导/反例 |
| **英语难度** | 词汇简单、语速慢、句子短 | 常规学术表达、正常语速 | 接近 native 的快速流畅表达 |
| **压力程度** | 全程温和，绝不打断 | 偶尔打断纠正，正常施压 | 高强度施压，连环追问、质疑答案 |

「自由描述」框可追加任意要求，例如「多问科研细节」「全程严肃别夸奖」。

### 🏫 目标院校风格

在「学校风格」页建立院校档案：学校名 + 报考类型（**复试 / 保研 / 夏令营**）+ 多条风格笔记。笔记内容就是你搜集到的学长学姐经验、真题回忆、该校偏好（爱问什么、有无英语环节、是否施压）。支持**导入 PDF / Word / TXT** 批量录入已整理的资料。

面试开始时绑定某所学校，面试官的系统提示词里就会带上这些笔记，出题与追问尽量贴合该校真实风格。

### 📚 资料驱动出题

「资料库」页分三类管理，导入即解析为文本缓存：

| 分类 | 用途 | 面试时喂给 AI 的量 |
|---|---|---|
| 英语资料 | 词汇表、话题模板、口语素材 | 最多 8000 字 |
| 专业课资料 | 笔记、教材摘要、真题答案 | 最多 8000 字 |
| 简历 | 一份最新简历（建议只放 1 份） | 最多 6000 字 |

- 支持格式：**PDF / Word(.docx) / Markdown / TXT**，可多选批量导入
- 列表显示页数（PDF）、字符数、导入时间；支持**全文预览**与删除（同时清理解析缓存）
- 各阶段是**独立对话**，不会把上一阶段的问答带进下一阶段，避免"串味"

### 🎙️ 语音交互

**识别（本地、不上传）**

- 引擎：`faster-whisper`（small 模型，CPU int8 推理），模型约 **464MB**，**一次性下载**，可断点续传
- 边说边出字：录音按 **2 秒**分块累积识别并实时预览，停止录音后再做一次完整识别校正
- 音频只写在本机临时目录，识别完即删；**不经过任何服务器**
- 装了引擎也能用键盘：输入框回车发送（英语阶段提示用英文回答）

**朗读（Edge TTS，免费、无需 Key）**

| | 可选音色 |
|---|---|
| 中文面试官 | 晓晓（女，自然）/ 晓伊（女，活泼）/ 云希（男，自然）/ 云健（男，沉稳） |
| 英语考官 | Aria（美，女）/ Jenny（美，女）/ Guy（美，男）/ Sonia（英，女） |

- 语速 **0.6x – 1.6x** 可调，支持中英文试听
- **只朗读"提问"**，点评/追问/提示不朗读（否则会刷屏打断你的思路）
- 合成结果按「文本+音色+语速」哈希缓存为 mp3，同一句话不重复合成

### 🤖 多模型 / 多模态

可同时配置多个 **OpenAI 兼容**服务商并随时切换，内置快速模板：

| 模板 | API 地址 | 默认模型 | 是否支持图片输入 |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | — |
| 通义千问 | `dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max` | ✅ |
| 智谱 GLM | `open.bigmodel.cn/api/paas/v4` | `glm-4v-plus` | ✅ |
| Kimi | `api.moonshot.cn/v1` | `moonshot-v1-8k` | — |
| OpenAI | `api.openai.com/v1` | `gpt-4o` | ✅ |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` | — |

- 每个服务商可自定义名称 / 地址 / 模型 / API Key，并有「测试连接」按钮
- 勾选**支持图片输入**的服务商，面试中可以用 🖼️ 按钮把**图片发给面试官看**（例如让他看你画的框图、白板推导照片）

### 📊 评分报告

面试结束后点「生成评分报告」，AI 逐项打分（每项 **0-10**，允许 0.5）+ 总评 + 改进建议。

| 环节 | 评分维度（共 16 项） |
|---|---|
| 🗣️ 自我介绍 | 内容结构 / 亮点突出 / 表达流畅 / 时长控制 |
| 🇬🇧 英语口语 | 流利度 / 发音 / 语法 / 内容质量 / 应变 |
| 📖 专业课 | 知识准确性 / 逻辑性 / 深度 / 追问应对 |
| 📄 简历问答 | 项目理解深度 / 回答一致性 / 临场应变 |

- **总分算法**：先算每个环节内部各维度的平均分，再对 4 个环节**等权平均**，得 0-10 分（保留 1 位小数）
- **总评**：120 字以内，指出最主要优势与不足，中肯不浮夸
- **改进建议**：3-6 条，按优先级排序，每条不超过 40 字
- **问答回放**：可展开查看完整面试对话
- 📤 **导出报告**：导出 Markdown 评分报告
- 📝 **导出我的回答**：只导出你说过的内容，便于自己复盘
- 💡 **生成参考答案**：按题号列出「答题要点 + 参考答案」——**面试过程中绝不会提前透露答案**（提示词里硬性禁止），只能结束后复盘看

### 🕘 历史与对比

- 保存每次练习记录：时间、绑定学校、风格预设、总分、时长
- **单击勾选最多 2 条 → ⚖️ 对比**：并排显示总分与各维度得分变化，进步/退步一目了然
- 双击直接打开该次报告；支持删除单条记录

### 🔒 隐私优先

- 面试资料、录音、报告、历史、模型全部在**本机数据目录**，没有任何上传
- 联网只有两件事：① 与**你自己配置的** AI 服务商通信；② Edge TTS 语音合成
- 语音识别本地推理，**音频不出本机**
- 无遥测、无统计 SDK

## 🚀 快速开始

### 系统要求

| | macOS | Windows |
|---|---|---|
| 系统 | macOS（Apple Silicon） | Windows 10 / 11 **x64** |
| 状态 | ✅ 已提供打包好的 `.dmg` | ⚠️ 代码已适配，但安装包**必须在 Windows x64 上打包**（原因见 [开发指南 §7](docs/开发指南.md#7-windows-打包)） |
| 额外依赖 | Python 3.9+（用于语音识别引擎） | 安装时勾选「Add Python to PATH」 |

> Linux 未适配、未验证。

### 安装（macOS）

1. 下载 Release 中的 `面试模拟器-*.dmg`
2. 拖入「应用程序」文件夹
3. 首次打开：**右键点击图标 → 打开**（应用未签名，会有"无法验证开发者"提示，属正常现象；之后双击即可）

### 首次配置（4 步，一次性）

| 步骤 | 位置 | 操作 |
|---|---|---|
| 1️⃣ **AI 服务商**（必需） | 设置 → AI 服务商 | 点「＋ 新增服务商」→ 用「快速模板」选 DeepSeek（或通义/智谱/Kimi/OpenAI/本地 Ollama）→ 填入 API Key → 点「🔌 测试当前服务商」确认可用 |
| 2️⃣ **语音识别**（可选） | 设置 → 语音识别 | ① 点「安装识别引擎」（自动建独立 Python 虚拟环境并装 faster-whisper，约 300MB，3-10 分钟）② 点「下载语音模型」（约 464MB，支持断点续传） |
| 3️⃣ **麦克风** | 系统设置 → 隐私与安全性 → 麦克风 | 允许「面试模拟器」使用麦克风 |
| 4️⃣ **导入资料** | 资料库 | 分别导入英语资料 / 专业课资料 / 简历（PDF / Word / MD / TXT） |

> 只想打字不想说话？第 2、3 步可以跳过，用键盘输入照样能练。

### 开始练习

1. 设置页确认题数与风格默认值
2. （可选）学校风格页录入目标院校
3. 模拟面试页 → 绑定学校 → 选风格预设（本次练习可临时改）→ 点 **🚀 开始面试**

## 🎬 一次完整练习长什么样

```text
① 自我介绍（倒计时 2:30）
   你：录音说自我介绍 → 顶部实时出字 → 说「完毕」
   面试官：点评你的自我介绍 → 追问一个相关问题（项目细节/为何选这个方向）

② 英语口语（5 题，全英文）
   面试官（英文朗读）：Could you tell me about your hometown?
   你：录音作答 → 面试官用英文简短点评 + 追问 1 轮 → 第 3/5 题

③ 专业课（6 题）
   面试官：基于你的专业课资料出题
   你：作答 → 面试官指出对/错/不足 → 按「追问深度」决定是否继续深挖
   不会？点 💡 提示 拿方向，或 🔄 换一题

④ 简历提问（5 题）
   面试官：结合简历 + 你刚才的自我介绍原文，深挖项目细节

⑤ 点「完成面试 →」
   → 📊 生成评分报告（约 20 秒）
   → 16 项维度分 + 总分 + 总评 + 3-6 条改进建议 + 问答回放
   → 💡 生成参考答案（逐题给答题要点与参考答案）
   → 📤 导出 Markdown，或回历史记录里和上次 ⚖️ 对比
```

## 🌐 哪些操作需要联网

| 操作 | 需要联网？ | 说明 |
|---|---|---|
| 面试提问、点评、追问、评分、参考答案 | ✅ 必须 | 走你自己配置的 AI 服务商 |

| 导入资料、看报告、历史对比 | ❌ 不需要 | 纯本地 |

## 📁 数据存在哪 / 备份与迁移

所有数据在「设置 → 数据目录」里可见：

| 平台 | 路径 |
|---|---|
| macOS | `~/Library/Application Support/interview-simulator/` |
| Windows | `%APPDATA%\interview-simulator\` |

```text
interview-simulator/
├── settings.json            # 设置（API Key、题数、风格、音色）
└── data/
    ├── materials/           # 导入的资料（english/  major/  resume/）
    ├── materials-index.json # 资料索引
    ├── schools.json         # 学校风格库
    ├── history/             # 面试记录 + 评分报告 + 参考答案
    ├── models/              # Whisper 语音模型（464MB，别删）
    ├── venv-whisper/        # 识别引擎的 Python 虚拟环境（别删）
    ├── audio/               # 录音临时文件 + TTS 缓存（可清理）
    └── logs/                # 识别日志（排查问题用）
```

- **备份**：复制整个 `interview-simulator` 文件夹即可
- **迁移**：把文件夹放到新电脑的同一位置（Windows 换机器同理）
- **升级/重装不丢数据**：数据目录固定，覆盖安装新版本不影响资料、模型与历史
- **重置**：删掉 `settings.json` 会回到默认设置（资料和历史仍在）

## ❓ 常见问题

**Q：macOS 提示"无法验证开发者"或"已损坏"？**
A：这是未签名应用的正常提示。**右键点击 App → 打开**；若仍拦截，去「系统设置 → 隐私与安全性」点「仍要打开」，之后正常双击即可。

**Q：一定要装语音识别吗？**
A：不必须。识别只是让你"说话代替打字"。跳过第 2、3 步，用底部输入框回车发送一样能完整练习。

**Q：安装识别引擎失败怎么办？**
A：先确认本机有 Python 3.9+（macOS 终端执行 `python3 -V` 能看到版本号）。仍失败时看设置页的报错信息，日志在数据目录的 `logs/whisper-worker.log`。

**Q：面试官会不会直接把答案告诉我？**
A：不会。提示词里硬性禁止透露任何参考答案，"提示"只给方向性关键词。完整参考答案在面试结束后点 💡「生成参考答案」才生成。

**Q：评分报告生成失败？**
A：通常是 API Key 余额不足、地址填错或网络问题（用「🔌 测试当前服务商」自查）；另外面试对话太短也可能导致模型返回格式异常，可换一次完整练习再试。

**Q：英语环节为什么一直是英文？**
A：这是设计如此——英语口语考官全程英文交流，其余三个阶段中文。

**Q：录音没反应 / 没有声音？**
A：三步排查：①系统麦克风权限是否已授权（设置页会显示状态）②麦克风是否被会议软件占用③中文面试官音色是否选对。另外设置页有「🎙️ 录音识别测试」，按住按钮说一句话即可验证「录音 → 识别」全链路（需模型已下载完成）。

**Q：语速/音色改了没效果？**
A：语音朗读只在**提问**时触发，点评和追问不朗读。另外请在设置页点「中文试听 / 英文试听」确认合成可用。

**Q：模型和 venv 文件夹能删吗？**
A：能删，但下次使用要重新下载（464MB）并重装引擎（约 300MB）。

**Q：能同时用多个 AI 服务商吗？**
A：可以。设置页可保存多个服务商并随时切换，例如平时用 DeepSeek、需要看图时切到多模态模型。

**Q：面试记录能导出吗？**
A：可以。报告页可导出「评分类 Markdown」和「我的回答汇总 Markdown」两种。

## 🛠 开发

### 环境要求

- Node.js ≥ 22
- **Python 3.9+**：语音识别引擎会在应用内自动创建独立虚拟环境（不污染系统）。
  Windows 上请确保 `python` 或 `py -3` 可用，并勾选安装时的「Add Python to PATH」
- 出安装包的平台：macOS(Apple Silicon) 出 dmg；**Windows 包必须在 Windows x64 机器上打**
  （`pdf-parse` 依赖平台原生模块 `@napi-rs/canvas`，详见 [开发指南 §7](docs/开发指南.md#7-windows-打包)）

### 常用命令

```bash
npm install          # 安装依赖
npm run dev          # 开发模式（热更新）
npm run typecheck    # 类型检查
npm run build        # 构建
npm run build:mac    # 打包 dmg（产物在 dist/）
npm run build:win    # 打包 Windows 安装包 + 免安装版（需在 Windows 上执行）
```

> 国内网络建议保留仓库内 `.npmrc`（Electron 二进制走国内镜像）。

### 技术栈

Electron 43 · electron-vite 5 · React 19 · TypeScript 5.9 · Vite 7
OpenAI 兼容 API（DeepSeek / 通义 / 智谱 / Kimi / OpenAI / Ollama）· faster-whisper（本地识别）· Edge TTS（语音合成）· pdf-parse / mammoth（资料解析）

