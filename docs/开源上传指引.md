## 📝 上传前：替换占位符（3 步）

### 步骤 1：替换文件中的占位符

全局替换 `Filppp` 为你的 GitHub 用户名（共 4 个文件）：

```bash
cd ~/interview-simulator
# 把下面的 yourname 换成你的 GitHub 用户名
grep -rl "Filppp" . --exclude-dir=node_modules --exclude-dir=.git | while read f; do
  sed -i '' "s/Filppp/yourname/g" "$f"
done
```

涉及文件：`README.md`、`LICENSE`、`package.json`（author/repository/homepage）。

### 步骤 2：（可选）把提交历史作者也换成你的账号

现在历史上 15 个提交的作者是 `Filppp` 占位符。若希望这些提交在你的 GitHub 主页正确显示为你的贡献：

```bash
cd ~/interview-simulator
# 1) 先在 GitHub 账号设置里添加隐私邮箱（Settings → Emails → Keep my email private）
# 2) 然后执行（换成你的用户名）：
git filter-branch -f --env-filter '
export GIT_AUTHOR_NAME="yourname"
export GIT_AUTHOR_EMAIL="yourname@users.noreply.github.com"
export GIT_COMMITTER_NAME="yourname"
export GIT_COMMITTER_EMAIL="yourname@users.noreply.github.com"
' --tag-name-filter cat -- --all
rm -rf .git/refs/original && git reflog expire --expire=now --all && git gc --prune=now
```

> 若不执行步骤 2：历史提交作者显示为 `Filppp`，功能与使用完全不受影响，只是不计入你的贡献图。

### 步骤 3：设置本地 Git 身份（以后的新提交）

```bash
git config user.name "yourname"
git config user.email "yourname@users.noreply.github.com"
```

## 🚀 上传到 GitHub

### 1. 创建远程仓库

网页操作：GitHub → New repository
- Repository name：`interview-simulator`
- **不要**勾选 "Add a README file / .gitignore / license"（保持空仓库）

### 2. 关联并推送

```bash
cd ~/interview-simulator
git remote add origin https://github.com/yourname/interview-simulator.git
git branch -M main
git push -u origin main
```

### 3. 认证方式（二选一）

| 方式 | 说明 |
|---|---|
| **HTTPS + PAT**（简单） | 密码处粘贴 **Personal Access Token**（GitHub → Settings → Developer settings → Tokens (classic) → 勾选 `repo`），**不要**用账号密码 |
| **SSH**（推荐长期用） | 生成密钥 `ssh-keygen -t ed25519 -C "yourname@users.noreply.github.com"`，把公钥加到 GitHub → Settings → SSH keys，然后 remote 用 `git@github.com:yourname/interview-simulator.git` |

⚠️ **重要**：不要把 Token 写进代码、README 或 remote URL 里（`https://token@github.com/...` 会泄漏）。macOS 可用钥匙串记住凭证。

## ⚠️ 关于隐私的最终提醒

- **本项目不包含你的任何个人数据**（资料、简历、Key、历史报告都在本机用户数据目录）。
- 你自己后续开发时，注意别把 `settings.json` 或资料文件复制进项目目录 —— `.gitignore` 已做基础防护，但根本原则是：**个人数据永远放用户数据目录，不进仓库**。
- 若曾在别处（如聊天、截图）暴露过 API Key，建议到服务商后台吊销重发。
